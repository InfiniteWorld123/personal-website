## القرار التجاري المختصر

- الاسم المختصر أمام العميل: **Individuelle Software**.
- الاسم الموسع عند الحاجة: **Individuelle Software & Business-Systeme**.
- السعر المنشور: **يبدأ من ٢٩٩٠ يورو**.
- لا توجد باقات ثابتة للـMVP أو الأنظمة الكبيرة.
- يتحدد السعر بعد محادثة أولى ومراجعة تقنية هادئة للنطاق.
- عندما لا يمكن تقدير المشروع بأمان، تبدأ مرحلة اكتشاف مدفوعة ثم يصدر عرض تنفيذ مستقل.
- الدفعات الافتراضية للمشروعات المخصصة: **٤٠٪ / ٣٠٪ / ٣٠٪** مرتبطة ببداية العمل ومرحلة قابلة للفحص والقبول النهائي.
- لا يُعدّل المطور نظاماً خارجياً أو Codebase غير مألوف عندما لا يستطيع فحصه واختباره واستعادته بأمان.

## ما نبيعه؟

نبيع تطبيق ويب أو نظام عمل مصمماً حول مشكلة واضحة، مثل:

- Booking system.
- Customer أو Employee portal.
- Admin dashboard.
- Subscription application أو SaaS MVP.
- نظام داخلي لإدارة عملية أو بيانات.
- Authentication وPermissions.
- Payments وBilling.
- CMS مخصص عندما يتجاوز نطاق الموقع البسيط.
- APIs وAutomations وIntegrations داخل نظام نبنيه ونستطيع اختباره.
- Product analytics أو Reporting عندما يخدمان قراراً أو عملية واضحة.

لا نبيع قائمة تقنيات ولا نعد بنتيجة تجارية لا نستطيع التحكم بها. نبدأ بأصغر نسخة تحقق قيمة حقيقية ثم نضيف المراحل عند الحاجة.

متجر Shopify لا ينتقل إلى هذه الفئة لمجرد زيادة عدد المنتجات أو استخدام واجهة Headless. ينتقل عندما يصبح الجزء المخصص المسؤول عن Workflow أو بيانات أو صلاحيات أو عمليات مستقلة هو جوهر المشروع، ويكون Shopify قناة بيع ضمن نظام أكبر.

## ما سيظهر للعميل لاحقاً؟

لا تظهر كل هذه التفاصيل على الموقع. يكفي أن يرى العميل:

- ما نوع المشكلات التي يمكن حلها.
- أمثلة حقيقية من المشاريع.
- السعر الابتدائي **ab 2.990 €**.
- أن السعر النهائي يأتي بعد فهم النطاق.
- خطوات العمل المختصرة.
- دعوة لمحادثة أولى.

التفاصيل الكاملة توضع في عرض المشروع أو ملف PDF واضح، ولا تُحمّل الصفحة الرئيسية بكل القواعد الداخلية.

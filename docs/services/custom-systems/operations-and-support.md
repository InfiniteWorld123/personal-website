# الاستضافة والتشغيل والدعم

## اختيار البيئة

لا يوجد Hosting واحد يناسب كل نظام. تُختار البيئة بعد معرفة قاعدة البيانات والحمل والمهام الخلفية والتخزين ومتطلبات الاستعادة والأمان.

يمكن استخدام Serverless أو Managed services أو VPS وDocker عندما يخدم ذلك المشروع. لا يُختار VPS لأنه يبدو أرخص إذا كان سيضيف مسؤولية تحديث ومراقبة ونسخ احتياطي لا يدفع العميل مقابلها.

## الحسابات والفواتير

الأصل أن ينشئ العميل الحسابات أو يملك Organization المشروع ويدفع مباشرة مقابل:

- Cloud hosting أو Server.
- Database وObject storage.
- Transactional email وSMS.
- Payment provider.
- Analytics وError tracking وMonitoring.
- Domain وDNS.

يحصل المطور على صلاحيات مناسبة للعمل. لا توضع عدة أنظمة عملاء حرجة داخل حساب شخصي واحد إذا كان ذلك يعرقل الفصل أو التسليم أو الأمان.

## ما يدخل في تكلفة البناء؟

- إعداد بيئتي Development وProduction ضمن النطاق.
- أول عملية Deployment.
- إعداد المتغيرات والأسرار بطريقة مناسبة.
- فحص المسارات الأساسية بعد النشر.
- تعليمات التشغيل والتسليم المتفق عليها.

لا يدخل تلقائياً:

- فواتير الاستخدام الشهرية.
- مراقبة مستمرة أو On-call.
- إدارة نظام التشغيل إلى أجل غير محدد.
- ترقية الخطط بسبب نمو العميل.
- إصلاح تغييرات الأطراف الثالثة بعد التسليم.

## لا يوجد اشتراك شهري إجباري

يستطيع العميل بعد التسليم أن يدير النظام بنفسه أو مع مزود آخر إذا تسلم ما اتُّفق عليه. لا يُفرض اشتراك لمجرد إبقاء الشيفرة موجودة.

لكن النظام يحتاج جهة تتحمل الأعمال المستمرة. إذا لم يشترِ العميل إدارة أو صيانة، لا يفترض أن المطور يراقب النظام أو يصلح تغيرات الأطراف الثالثة مجاناً.

## التشغيل المُدار

يمكن للعميل شراء إدارة شهرية مستقلة تشمل فقط ما يذكره العقد، مثل:

- مراقبة التوفر والأخطاء والاستهلاك.
- مراجعة النسخ الاحتياطي وإمكان الاستعادة.
- تحديثات أمنية واعتماديات مخططة.
- Deployment وRollback.
- تقرير أو مراجعة تشغيل دورية.
- زمن استجابة محدد للحوادث.

سعر إدارة المواقع التعريفية البالغ ٣٩ يورو شهرياً لا ينتقل إلى الأنظمة المخصصة. النظام الذي يحتوي على قاعدة بيانات ومستخدمين وعمليات يحتاج تقديراً مبنياً على ساعات المسؤولية والحمل والمخاطر.

## Support وMaintenance وNew Development

**Support** يساعد الأشخاص على استخدام النظام أو تشخيص البلاغ، مثل التدريب والأسئلة والمساعدة المحدودة في الإعدادات.

**Maintenance** عمل وقائي، مثل تحديث الاعتماديات ومراجعة السجلات واستهلاك الخدمات واختبار Backup وRestore وتوافق Providers.

**New Development** هو إضافة خصائص أو تقارير أو Integrations أو تغيير Workflow، ويحصل على عرض مرحلة جديدة أو Time budget منفصل.

سعر العمل الإضافي الحالي **٣٥ يورو لنصف ساعة و٧٠ يورو للساعة**، لكن العمل داخل نظام معقد قد يحتاج أولاً تقدير أثر قبل بدء التنفيذ.

## النسخ الاحتياطي والاستعادة

- وجود Backup لا يكفي؛ يجب تحديد من يراقبه وكيف تُختبر الاستعادة.
- يحدد العقد مدة الاحتفاظ وRPO وRTO فقط عندما يدفع العميل مقابل مستوى خدمة واضح.
- قبل تغييرات خطرة يجب وجود نسخة أو مسار رجوع مناسب.
- لا يتحمل المطور مسؤولية تشغيل لم يشترها العميل أو تغييرات طرف آخر خارج الاتفاق، مع ترك صياغة المسؤولية للمحامي.

## الحوادث

- لا يوجد SLA تلقائي.
- الأولوية وزمن الاستجابة والإصلاح أشياء مختلفة ويجب تعريفها.
- الاستجابة الطارئة خارج ساعات العمل تحتاج اتفاقاً وتسعيراً منفصلين.
- قد يكون البلاغ سببه Provider أو استخداماً خاطئاً أو وصولاً من طرف آخر، وليس خطأ في الشيفرة.

## قابلية النقل ونهاية العلاقة

بعد السداد والتسليم يحصل العميل، بحسب النطاق، على:

- مستودع الشيفرة المتفق عليه.
- قائمة الخدمات والبيئات.
- بنية البيانات أو طريقة تصديرها.
- تعليمات النشر والتشغيل المشمولة.
- حساباته أو صلاحياته الإدارية.

عند انتهاء الإدارة تُلغى صلاحيات المطور غير المطلوبة، ويُحدد آخر Backup وطريقة تصدير البيانات وتاريخ توقف المراقبة والاستجابة. لا يعني النقل منح ملكية حصرية لمشروع البداية أو المكونات العامة.

# المسؤوليات القانونية ومسؤوليات العميل

> قائمة تخطيط داخلية وليست استشارة قانونية أو ضريبية. يجب أن يعتمد العميل نصوصه وعملياته مع محامٍ أو مزود قانوني ومستشار ضريبي مناسبين لألمانيا وأسواقه.

تنطبق قواعد [التسليم والملكية والمسؤوليات](../shared/delivery-ownership-and-responsibilities.md) و[النطاق والتسعير والدفعات](../shared/scope-pricing-and-payments.md) و[ما بعد الإطلاق](../shared/post-launch-and-support.md).

## مسؤولية العميل التجارية

العميل مسؤول عن:

- صحة المنتجات والأسعار والمخزون والأوصاف والادعاءات.
- امتلاك حقوق الصور والعلامات والمحتوى.
- تصنيف الضرائب ومعدلاتها وقواعد الفواتير.
- الشحن والتسليم والإرجاع والاسترداد والضمان.
- النصوص القانونية مثل Impressum وDatenschutzerklärung وWiderruf وAGB عند استخدامها.
- التحقق من متطلبات المنتجات المقيدة أو الرقمية أو الغذائية أو الطبية.
- إدارة الطلبات وخدمة العملاء بعد التسليم ما لم يوجد عقد منفصل.

## مسؤوليتنا التقنية

ننفذ النصوص والإعدادات والخيارات التي يعتمدها العميل ضمن النطاق، وننبه إلى المخاطر المعروفة، لكننا لا نضمن أن Theme أو App أو إعداداً تقنياً يجعل النشاط قانونياً تلقائياً.

لا نستخدم عبارة **rechtssicher** كوعد مطلق. يمكن القول إن المتجر مجهز تقنياً لإدخال النصوص والإعدادات التي يقدمها العميل أو مزوده القانوني.

## الدفع والبيانات

- يختار العميل مزود الدفع ويعتمد شروطه ورسومه.
- يجب مراجعة Consent وCookies وAnalytics والتطبيقات الخارجية قبل التفعيل.
- تُحدد أدوار حماية البيانات واتفاقيات المعالجة ومواعيد الحذف والاحتفاظ.
- لا تُنقل بيانات العملاء من متجر قديم دون فحص قانوني وتقني مناسب.

## Themes وApps

- يشتري العميل التراخيص باسمه عندما يكون ذلك ممكناً.
- لا نضمن استمرار App أو سعره أو توافقه إلى الأبد.
- يوضح العرض ما إذا كان Custom Code قابلاً لإعادة الاستخدام وما الذي يحصل عليه العميل بعد السداد.
- تغيير شروط Shopify أو التطبيقات بعد التسليم ليس Feature مجانية ضمن المشروع الأصلي.

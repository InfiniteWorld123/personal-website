# الاستضافة والتشغيل والدعم

## فصل مسؤولية Shopify عن مسؤوليتنا

توفر Shopify استضافة المتجر الأساسي وشهادة الاتصال المشفر وتحديثات المنصة. لا نبيع للعميل Hosting مستقلاً لمتجر Theme قياسي، ولا نصف اشتراك Shopify بأنه جزء من سعر البناء.

تبقى علينا ضمن المشروع مسؤولية إعداد ما اتُّفق عليه وفحصه وتسليمه، مثل Theme والنطاق والتطبيقات وطرق الدفع والشحن وTest Orders.

## الحسابات والملكية

- يكون Shopify Store باسم العميل أو داخل Organization يملكها.
- يدفع العميل Shopify وApps وDomain مباشرة قدر الإمكان.
- نحصل على Partner أو Collaborator access بالصلاحيات اللازمة فقط.
- لا نطلب كلمة المرور الشخصية عندما توجد طريقة وصول رسمية.
- تُزال صلاحياتنا أو تعدل بعد التسليم بحسب عقد الدعم.

## بعد الإطلاق

تشمل الخدمة الأساسية ثلاثين يوماً لإصلاح أخطاء تنفيذ النطاق. لا تشمل الفترة:

- إضافة منتجات أو صفحات أو Features جديدة.
- إدارة الطلبات والعملاء والمخزون.
- مشاكل بيانات أدخلها العميل أو طرف آخر.
- تغييراً فرضه App أو Provider بعد التسليم.
- مراقبة مستمرة أو استجابة طارئة.

## الدعم الاختياري

يمكن تقديم دعم أو صيانة بعرض منفصل يحدد:

- أسئلة الاستخدام والتدريب الإضافي.
- تغييرات المحتوى والمنتجات.
- مراجعة Apps والتكاليف والتوافق.
- تعديلات Theme الصغيرة.
- فحص الأخطاء بعد تحديثات مهمة.
- ساعات العمل وقناة التواصل وزمن الرد.

لا نعتمد حالياً باقة شهرية ثابتة للمتاجر قبل قياس عبء أول مشروعات حقيقية. سعر إدارة المواقع البالغ ٣٩ يورو لا ينتقل تلقائياً إلى Shopify.

## Headless أو Custom Apps

عند وجود Hosting خارجي أو Backend أو Custom App، لا تعود Shopify مسؤولة عن كل النظام. يجب تحديد مراقبة ونشر وأسرار ونسخ احتياطي وRollback وتكاليف تشغيل كل جزء، ويُسعّر ذلك ضمن المشروع أو عقد تشغيل منفصل.

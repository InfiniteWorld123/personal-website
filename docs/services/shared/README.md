# القواعد المشتركة بين الخدمات

> هذا المجلد هو المرجع الداخلي للقواعد التي تنطبق على Websites وShopify Onlineshops وIndividuelle Software. تحتفظ كل فئة بنطاقها وأسعارها وطريقة تشغيلها الخاصة، وتعلو قواعدها المتخصصة على هذا المرجع عندما يوجد اختلاف معلن.

## لماذا يوجد مرجع مشترك؟

الهدف هو منع تكرار القواعد نفسها بصيغ مختلفة داخل كل خدمة، وخصوصاً قواعد:

- تحديد النطاق وتغييراته.
- التسعير والدفعات.
- الأخطاء والميزات الجديدة.
- ملكية الحسابات والبيانات وحقوق استخدام الشيفرة.
- تكاليف الأطراف الثالثة.
- التشغيل والدعم والصيانة بعد الإطلاق.
- حدود الوعود والمسؤوليات.
